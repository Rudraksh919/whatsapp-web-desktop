# AGENTS.md

## What this is
Windows-only Tauri v2 (Rust) + WebView2 wrapper around WhatsApp Web (`https://web.whatsapp.com/`).
All UI is the remote WhatsApp page plus `src-tauri/src/inject.js`; there is no local frontend, no
bundler, and no frontend build step. `dist-ui/index.html` is a committed one-line stub used only as
Tauri's `frontendDist`. Only ~16 files are tracked.

## Do not be misled by leftovers
- `node_modules/` and `dist/` are stale **Electron** artifacts from the old `main` branch. They are
  unused here and there is **no `package.json`** on this branch. Do not run `npm`/`node`.
- `src-tauri/gen/` and `src-tauri/permissions/` are generated by `tauri-build` and gitignored.
  Never hand-edit them.

## Branches
`main` is the old Electron/Linux line (`package.json`, `main.js`, `preload.js`). Current work lives
on the **`tauri-windows`** branch. `windows` is another stale branch.

## Commands
Run from `src-tauri/` (that is where `Cargo.toml` lives):
- `cargo tauri dev` — run the app
- `cargo tauri build` — NSIS installer → `src-tauri/target/release/bundle/nsis/`
- `cargo test` — the only tests (2 unit tests in `main.rs`); no JS/integration/CI tests exist
- `cargo tauri icon icons/icon.svg` — regenerate the icon set from the source SVG

Requires Rust + MSVC build tools and `tauri-cli` v2
(`cargo install tauri-cli --version "^2" --locked`).

## Architecture
- `src-tauri/src/main.rs` — the whole backend: window/tray setup, commands, WebView2 memory trim,
  Windows toast, and the code-drawn unread badge (`with_badge`).
- `src-tauri/src/inject.js` — injected into the **remote** page as an initialization script. Guards
  on `location.origin`, replaces `window.Notification`, syncs the unread count from the page title,
  and adds the privacy-blur / open-downloads buttons. This is where the page-facing features live.
- `src-tauri/capabilities/whatsapp.json` — grants the three commands to the remote origin.
- `src-tauri/build.rs` / `tauri.conf.json` — build wiring.

## Gotchas
- **Adding/renaming a Tauri command needs three coordinated edits**: the command list in
  `build.rs` (`AppManifest::new().commands([...])`), the `invoke_handler` in `main.rs`, and the
  `permissions` array in `capabilities/whatsapp.json` (entries are the autogenerated
  `allow-<command>` files). Missing any one silently drops the invoke.
- **Version is duplicated**: bump both `src-tauri/Cargo.toml` and `src-tauri/tauri.conf.json`.
- Plugin setup order matters: `single-instance` must be registered first, and the `opener` plugin is
  deliberately built with `open_js_links_on_click(false)` so custom `on_new_window`/`on_navigation`
  handlers can open links (see the comments in `main.rs`).
- Close hides to tray; only tray "Quit" exits the process. Windows-only code is behind
  `#[cfg(windows)]` with non-Windows stubs, so it compiles cross-platform but only behaves on Windows.
